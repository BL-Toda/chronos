# Chronos 法務ロールアウト計画（段階戦略）2026-08-17 確定

批判的レビュー（docs/legal/ja/review-20260817.md）を受け、全法域同時対応ではなく段階的に開放する。
**本書が法務ドラフト改訂・実装要件の正。** ここに無い事項は review の推奨に従う。

## Phase 1 — ローンチ（日本 + 英語版）

| 項目 | 決定 |
|---|---|
| 提供言語 | 日本語（原本）・英語 |
| Free利用 | 全世界（ただしEU・韓国・台湾向けの能動的マーケティングは行わない。現地語UIも提供しない） |
| **Pro課金** | **日本居住者のみ**（Stripe Checkoutで請求先国を日本に限定）。海外VAT・自動更新法・撤回権の各国要件をPhase 1では負わない |
| 居住国の取得 | 登録時に国を選択（IP推定を初期値、ユーザー訂正可）。決済時はStripe請求先国を正とする。プライバシーポリシーの取得項目に追加 |
| 契約言語 | **契約言語主義**: ユーザーが契約時に選択した表示言語の版が適用。多言語版間の疑義は消費者に有利に解釈。「日本語版優先」条項は廃止 |
| 年齢 | 登録16歳以上。**Pro購入は18歳以上（居住国の成年年齢以上）に限定** |
| AI学習利用 | ユーザーコンテンツ・AI入力を当社モデル学習にも第三者への学習提供にも**利用しない**。方針変更時は事前同意 |
| 免責構造 | 「故意重過失を除き責任を負わない」型を全廃し、**上限付き責任制限**（軽過失時: 直近12ヶ月の支払額または¥10,000の高い方）に一本化 |
| 価格 | 規約本文から価格表を分離。料金ページ＋特商法表記が価格の正、規約は手続のみ |
| Free降格時 | 上限超過分は閲覧・書き出し可／編集不可／公開状態維持／埋め込みは停止 |
| 通知削除手続 | 独立文書「コンテンツポリシーおよび通知・措置の手続」を新設し規約から参照。権利侵害申告（プロ責法・DMCA相当）と規約違反通報を分離。受領確認・結果通知・理由陳述・異議申立（14日）・反復侵害者ポリシー |
| 通報者 | 権利侵害申告は氏名・連絡先必須。規約違反通報は匿名可 |
| AI生成表示 | 未検証のAI下書き由来イベントには公開画面でも「AI下書き・未検証」表示を維持（EU AI Act 50条対応も兼ねる） |
| 米国居住者 | Phase 1はFreeのみ。仲裁・クラスアクション放棄は採用しない（小規模事業者として大量仲裁コストを回避、リスク了解済み）。付則Dは CalOPPA 対応の最小構成 |
| 法定公表 | 代表者氏名・所在地番地・電話（または即応手段）は公開する前提（[TODO] 値の提供待ち） |
| 付則の扱い | 総則に「付則のない地域の居住者にも共通本文を適用し、居住国の強行法規による保護は失われない」を明記。EU/韓国/台湾の付則は Phase 3 用ドラフトとして別ファイルに退避 |

## Phase 2 — 米国・英語圏へのPro開放（時期未定）

- CA自動更新法（更新前通知・トライアル転換通知・解約確認）対応の決済フロー
- DMCA §512 指定代理人登録・反復侵害者ポリシー公表
- 出訴期限・小額裁判所例外の付則D拡張、州別ARL・プライバシー法確認
- 英・加・豪の消費者法（ACL非除外保証等）の確認、Stripe Tax による売上税

## Phase 3 — EU / 韓国 / 台湾（現地語版とともに）

- EU: GDPR Art.27 代表者・DSA Art.13 法定代理人の選任、Impressum、撤回権告知（デジタル・サービス構成）＋法定書式、解約ボタン（BGB §312k）、年額更新の月単位化、Cookie同意（拒否同等）、フォントのセルフホスト、VAT OSS
- 韓国: PIPA 国外移転の告知構成、保護責任者、韓国語処理方針掲示、電子商取引法表示、通信販売業申告要否
- 台湾: PDPA 第8条告知、消保法（審閲期間・解除権）、繁体字版、VAT登録閾値
- 各国ネイティブ弁護士による翻訳版レビューを公開条件とする
