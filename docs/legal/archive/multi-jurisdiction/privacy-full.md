## 2. 適用範囲・年齢

### 2.1 適用範囲

本ポリシーは、本サービスを閲覧・利用するすべての方（アカウントを作成しない閲覧者、ウェイトリストに登録した方を含む）に適用されます。

本サービスから外部サービス（出典として登録されたURL、Stripe の決済ページ、Google / Apple のログイン画面など）に移動した後の情報の取扱いは、各サービスのプライバシーポリシーに従います。

本サービスは16歳以上の方を対象としています。当社は、16歳未満の方の個人情報を意図して取得しません。有料プラン（Pro）の購入は18歳以上（居住国の成年年齢以上）の方に限ります。詳細は「13. 子ども・若年者の利用」をご覧ください。

## 5. AI機能におけるデータの取り扱い

本サービスには、年表の「下書き」を自動生成する機能（AI下書き）と、既存の年表・イベントの編集を支援する機能（AIアシスト。以下あわせて「AI機能」）があります。AI機能に関するデータの取扱いは次のとおりです。

### 5.1 送信されるデータ

AI機能を利用すると、あなたが入力したテーマ・条件・編集指示と、処理に必要な範囲の年表・イベントの内容（タイトル・日付・要約・本文・出典・信憑性メモなど）が、当社のサーバーを経由して Anthropic, PBC（米国）が提供する Claude API に送信されます。

AI機能を利用しない限り、ユーザーコンテンツが Anthropic に送信されることはありません。また、当社は、AI機能の処理に不要な情報（メールアドレス、Stripe 顧客ID、IPアドレスなど）を Claude API に送信しません。

### 5.2 Anthropic 側での取扱い

当社は、Anthropic と個別の契約を結んでいるのではなく、Anthropic の商用利用規約（Commercial Terms of Service）およびデータ処理に関する付属条件に基づいて Claude API を利用しています。同規約上、API を通じて送信された入力と出力は Anthropic のモデル学習に利用されないものとされており、当社はこの条件のもとで利用しています。ただし、Anthropic は不正利用の監視のために入力・出力を一時的に保持することがあります（現行の条件では最長30日程度）。当社は、Anthropic の条件が変更された場合、本節を更新し、あなたに不利な変更については第14節に従ってお知らせします。[TODO: 公開前に Anthropic の最新の Commercial Terms / Usage Policy / データ保持条件を再確認し、保持日数の記載を確定する。ゼロデータ保持オプションの採否を決める]

### 5.3 生成結果の性質と「未検証」表示

AI機能の出力は、あくまで「下書き」であり、内容の正確性は保証されません。AI機能が生成したイベントには、信憑性の区分として「未検証（unverified）」が初期値として設定されます。あなたは公開前に内容を確認し、必要に応じて出典を追加し、信憑性の区分を変更することができます。

未検証のままのAI下書き由来のイベントは、閲覧者にAI生成であることが分かるよう、公開画面・埋め込み表示でも「AI下書き・未検証」の表示を維持します。この表示は、あなたが内容を確認して信憑性の区分を変更するまで残ります。

### 5.4 ユーザーコンテンツを学習に利用しないこと

AI機能で生成された下書きを含め、年表・イベントなどのユーザーコンテンツはあなたの管理下に置かれます。当社は、ユーザーコンテンツおよびAI機能への入力を、当社独自のAIモデルの学習に利用せず、第三者にモデル学習のために提供もしません。この方針を変更する場合は、変更前にあなたの同意を求めます。当社が Anthropic 以外のAI事業者を新たに利用する場合は、第6節の委託先一覧を更新し、第14節に従ってお知らせします。

### 5.5 利用回数の記録

AI機能の利用回数（Free プランの月間上限の管理に必要な範囲）を、アカウントに紐づけて記録します。

### 8.3 Google Analytics 4 と同意

当社は、本サービスの利用状況を把握するために Google Analytics 4（GA4）を利用します。GA4 に関する取扱いは次のとおりです。

- 初回訪問時に表示される同意バナーには「同意する」と「拒否する」を同等の大きさ・目立ちやすさで表示します。「同意する」を選択するまで GA4 のタグは読み込まれず、データは送信されません。「拒否する」を選択した場合、または選択しなかった場合、GA4 は発火しません
- 埋め込みウィジェット（iframe）には GA4 を搭載しておらず、同意バナーも表示しません
- ブラウザの Global Privacy Control（GPC）信号を受信した場合、同意が得られていないものとして扱います [推奨値]
- GA4 では IP アドレスは Google 側で保存されず、当社は個人を特定できる形で解析データを利用しません。Google シグナル（広告用データの連携）は無効にしています
- 同意はいつでも撤回できます。フッターの「Cookie設定」から選択を変更してください
- Google によるデータの取扱いは、Google のプライバシーポリシーおよび「Google のサービスを使用するサイトやアプリから収集した情報の Google による使用」をご確認ください
- Google Analytics オプトアウト アドオン（https://tools.google.com/dlpage/gaoptout）を利用してブラウザ全体で無効化することもできます

### 8.4 ブラウザ設定による制御

ブラウザの設定により Cookie の受け入れを拒否したり削除したりできます。ただし、必須の Cookie を無効化すると、ログインなど本サービスの一部機能が利用できなくなります。
