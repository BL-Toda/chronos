## 付則B 韓国にお住まいの方（個人情報保護法・PIPA）

本付則は、大韓民国にお住まいの方に適用されます。当社は、韓国語版の個人情報処理方針を本サービスのウェブサイトに掲示します。

### B.1 収集項目・目的・保存期間

| 区分 | 収集項目 | 収集・利用目的 | 保存期間 |
|---|---|---|---|
| 必須（会員登録） | メールアドレス、表示名、OAuthプロバイダ識別子、居住国 | 会員識別・認証、サービス提供、通知、適用法令の判定 | 退会後30日以内に削除（バックアップは最長90日 [TODO: PITR 日数と突合]） |
| 必須（プロフィール） | ユーザー名 | 公開プロフィールの識別 | 同上 |
| 任意（プロフィール） | 自己紹介、アバター | プロフィール表示 | 同上 |
| 必須（サービス利用） | 年表・イベント・出典・信憑性メモ、いいね・ブックマーク、公開設定 | サービス提供 | 同上 |
| 必須（有料サービス。Phase 3 で韓国向け課金を開始する場合） | Stripe 顧客ID、プラン、請求履歴、請求先国 | 課金・請求・契約管理 | 電子商取引等における消費者保護に関する法律等に基づく期間（契約・決済記録5年、消費者不満・紛争処理記録3年）。日本法上の義務により最長10年 |
| 必須（AI機能） | 入力したテーマ・編集指示 | AI下書き・AIアシストの提供 | 処理ログ最長30日 |
| 任意（通報・問い合わせ） | 通報内容（対象年表のスナップショットを含む）、問い合わせ内容 | 通報対応、問い合わせ対応 | 通報: 対応完了後3年（通報者退会時は通報者IDを匿名化） / 問い合わせ: 対応完了後2年 |

| 任意（メール配信） | 機能案内メールの受信設定 | 新機能のご案内（同意した方のみ） | 同意撤回または退会まで |

必須項目の提供に同意しない場合、会員登録または該当機能を利用できません。任意項目の提供に同意しなくても、その他のサービスは利用できます。

### B.2 第三者提供

当社は、本人の同意または法令の根拠なく個人情報を第三者に提供しません（本文第6.3節）。

Google / Apple によるログイン、および Stripe による決済は、あなたが各社の画面で操作することにより開始され、当社から各社に渡る情報は認証・決済に必要な最小限のものです（本文第6.2節）。これらの提供が個人情報保護法上の「第三者提供」に当たると整理する場合、当社は該当する場面（ログイン時・決済時）で、提供を受ける者・目的・項目・保有期間・拒否権と不利益を明示して別途同意を取得します。[TODO: P3-5。弁護士確認のうえ、委託構成か第三者提供構成かを確定]

### B.4 個人情報の国外移転（第28条の8）

当社は、個人情報保護法第28条の8第1項第3号に基づき、個人情報の処理委託・保管のために必要な国外移転について、以下の事項を本処理方針に記載してお知らせします。この移転について、あなたの個別の同意は求めません。移転先は、当社の指示に基づいてのみ個人情報を取り扱い、当社は契約により安全性を確保しています。

| 事項 | 内容 |
|---|---|
| 移転される項目 | B.1 の各項目（各受託者の業務に必要な範囲） |
| 移転先の国 | 日本（当社。保管・処理）、米国（B.3 の各受託者）、Cloudflare のネットワーク所在国 |
| 移転の時期・方法 | サービス利用時に、暗号化された通信によりネットワーク経由で随時 |
| 移転を受ける者と連絡先 | 当社（babel, inc.、contact@chronos.tech）および B.3 の各受託者（各社の連絡先は各社ウェブサイト） |
| 移転を受ける者の利用目的 | 委託業務の遂行（本文第4節の目的の範囲） |
| 保有・利用期間 | B.1 の保存期間 |
| 移転を拒否する方法とその効果 | 契約の履行に不可欠な処理委託・保管のための移転については、拒否した場合、当社は退会（アカウント削除）の手続をご案内します。GA4 のためのGoogleへの移転は同意ベースで、拒否しても本サービスは利用できます |

### B.6 情報主体の権利

閲覧、訂正・削除、処理停止、同意撤回を請求できます。請求は contact@chronos.tech または設定画面から行え、当社は10日以内に対応します。法定代理人による請求も可能です。

### B.7 14歳未満の児童

当社は14歳未満の児童の個人情報を収集しません（本サービスは16歳以上を対象としています）。

### B.8 破棄手続き・方法

保有期間の経過または処理目的の達成後、遅滞なく破棄します。電子ファイルは復元不可能な方法で削除し、紙媒体は裁断または焼却します。法令により保存が必要な情報は、別のデータベースまたは保管場所に分離して保管します。

### B.9 個人情報の漏えい等への対応（第34条）

個人情報の漏えい・紛失・毀損を認識した場合、当社は、法令の定める期間内（原則72時間以内）に、漏えいした項目、時期と経緯、被害を最小化するためにあなたができること、当社の対応、相談窓口を、あなたに通知します。法令の定める規模・種類に該当する場合は、個人情報保護委員会または韓国インターネット振興院（KISA）に申告します。

### B.10 権益侵害の救済

個人情報侵害申告センター（privacy.kisa.or.kr、局番なし118）、個人情報紛争調停委員会（kopico.go.kr、1833-6972）、大検察庁サイバー捜査課（spo.go.kr、1301）、警察庁サイバー捜査局（ecrm.cyber.go.kr、182）に相談できます。

### C.2 本人の権利（第3条）

査詢または閲覧の請求、複製本の作成請求、補充または訂正の請求、収集・処理・利用の停止の請求、削除の請求。行使方法は本文第12.2節のとおりで、当社は査詢・閲覧・複製については15日以内、その他については30日以内に対応します（法令に基づきさらに延長することがあります）。

### C.3 提供しない場合の影響

必須項目（アカウント情報、ユーザー名、居住国、決済情報）を提供しない場合、アカウントの作成、該当機能の利用、有料プランの契約ができません。任意項目を提供しなくても、その他の機能は利用できます。

### C.4 個人資料の漏えい等への対応（第12条）

個人資料が窃取、漏えい、改ざんその他の侵害を受けたことを認識した場合、当社は、調査後、適切な方法で本人に通知します（侵害の事実、当社の対応、本人への影響と対処方法を含みます）。法令の定めに従い、主管機関への通報を行います。
