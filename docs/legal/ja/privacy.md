## 4. AI機能におけるデータの取扱い

本サービスには、年表の下書きを自動生成する「AI下書き」と、既存の年表・イベントの編集を支援する「AIアシスト」（あわせて「AI機能」）があります。

- **送信されるデータ**: AI機能を利用すると、あなたが入力したテーマ・条件・編集指示と、処理に必要な範囲の年表・イベントの内容が、当社のサーバーを経由して Anthropic, PBC（米国）の Claude API に送信されます。AI機能を利用しない限り、ユーザーコンテンツが Anthropic に送信されることはありません。メールアドレス、Stripe 顧客ID、IPアドレスなど処理に不要な情報は送信しません
- **Anthropic 側での取扱い**: 当社は Anthropic の商用利用規約に基づいて Claude API を利用しています。同規約上、API を通じて送信された入力と出力は Anthropic のモデル学習に利用されません。ただし、Anthropic は不正利用の監視のために入力・出力を一時的に保持することがあります（現行の条件では最長30日程度）[TODO: 公開前に Anthropic の最新の Commercial Terms・データ保持条件を再確認し、日数を確定]
- **生成結果は「未検証」**: AI機能の出力は下書きであり、正確性は保証されません。AI機能が生成したイベントには信憑性の区分「未検証」が初期値として設定され、あなたが内容を確認して区分を変更するまで、公開画面・埋め込み表示でも「AI下書き・未検証」の表示が維持されます
- **学習への利用**: 非公開・限定公開の年表およびAI機能への入力は、当社独自のAIモデルの学習に利用せず、第三者にモデル学習のために提供もしません。公開年表は、検索・分類・レコメンドやAI下書きの品質評価などサービス改善のために利用することがあります。公開年表をAIモデルの学習に用いる場合は、事前にお知らせし、設定で拒否できるようにします
- **利用回数の記録**: AI機能の利用回数（Free プランの月間上限の管理に必要な範囲）をアカウントに紐づけて記録します

### 6.3 Google Analytics 4 と同意

初回訪問時の同意バナーには「同意する」と「拒否する」を同等に表示し、「同意する」を選択するまで GA4 のタグは読み込まれず、データは送信されません。同意はフッターの「Cookie設定」からいつでも撤回できます。GA4 では IP アドレスは Google 側で保存されず、Google シグナル（広告用データの連携）は無効にしています。埋め込みウィジェットには GA4 を搭載していません。ブラウザの設定により Cookie を拒否・削除することもできますが、必須の Cookie を無効化するとログインなど一部機能が利用できなくなります。

## 7. 公開される情報

本サービスは年表を共有するためのサービスです。以下の情報は、あなたの設定に応じて第三者が閲覧できます。

- **「公開」に設定した年表**（イベント・レイヤー・出典・信憑性メモ・いいね数・ブックマーク数・「AI下書き・未検証」表示を含む）: すべての人が閲覧できます。Explore に掲載され、検索エンジンやSNSのプレビューに取得・表示されることがあります
- **「限定公開」に設定した年表**: 共有URLを知っている人が閲覧できます。Explore・公開プロフィールには掲載されず、検索エンジンにインデックスされないよう設定しますが、URLが転送された場合は閲覧を防げません
- **「非公開」の年表**（初期設定）: 本人のみ
- **公開プロフィール**（`chronos.app/@username`）: ユーザー名、表示名、自己紹介、アバター、公開年表の一覧といいね数を、すべての人が閲覧できます
- **埋め込みウィジェット（Pro）**: 埋め込み先のページを閲覧する人

公開設定を「非公開」に戻した後も、検索エンジンのキャッシュや第三者が保存したコピーが一定期間残ることがあります。メールアドレス、Stripe 顧客ID、居住国、いいね・ブックマークした年表の一覧、AI機能への入力内容は公開されません。年表に実在の人物に関する情報を記載して公開する場合、その情報の取扱いについて、あなた自身が法令上の責任を負うことがあります。

## 9. 安全管理措置

当社は、個人情報の漏えい、滅失、毀損の防止のため、次の措置を講じます。

- **組織的措置**: 個人情報の取扱いに関する責任者の設置、漏えい等事案発生時の対応手順の整備

- **外的環境の把握**: 委託先が所在する国の制度を把握したうえでの安全管理措置（第5.3節）

漏えい等が発生し、あなたの権利利益を害するおそれが大きい場合には、法令に従い、個人情報保護委員会への報告と本人への通知を行います。
