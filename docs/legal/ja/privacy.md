## 2. 適用範囲・年齢

### 2.1 適用範囲

本ポリシーは、本サービスを閲覧・利用するすべての方（アカウントを作成しない閲覧者、ウェイトリストに登録した方を含む）に適用されます。

本サービスは16歳以上の方を対象としています。当社は、16歳未満の方の個人情報を意図して取得しません。詳細は「13. 子どもの利用」をご覧ください。

## 5. AI機能におけるデータの取り扱い

本サービスには、年表の「下書き」を自動生成する機能（AI下書き）と、既存の年表・イベントの編集を支援する機能（AI Edit Assist。以下あわせて「AI機能」）があります。AI機能に関するデータの取扱いは次のとおりです。

### 5.1 送信されるデータ

AI機能を利用すると、ユーザーが入力したテーマ・条件・編集指示と、処理に必要な範囲の年表・イベントの内容（タイトル・日付・要約・本文・出典・信憑性メモなど）が、当社のサーバーを経由して Anthropic, PBC（米国）が提供する Claude API に送信されます。

AI機能を利用しない限り、ユーザーコンテンツが Anthropic に送信されることはありません。また、当社は、AI機能の処理に不要な情報（メールアドレス、Stripe 顧客ID、IPアドレスなど）を Claude API に送信しません。

### 5.2 モデルの学習に使用されないこと

Anthropic の API 利用条件では、API を通じて送信されたデータは Anthropic のモデルの学習に使用されないとされています。当社は、この条件を前提として Anthropic を利用しています。

### 5.3 生成結果の性質と「未検証」フラグ

## 8. Cookie・localStorage・アクセス解析

### 8.1 Cookie と localStorage の一覧

|---|---|---|---|---|
| 認証セッション（Cookie） | Supabase Auth のセッション・リフレッシュトークン | ログイン状態の維持、CSRF対策 | 必須 | セッション終了またはログアウトまで（リフレッシュトークンは最長30日 [推奨値]） |
| 同意状態（Cookie / localStorage） | `chronos_consent` [TODO: 実装名] | Cookie同意バナーの選択内容の記憶 | 必須 | 12ヶ月 |

| アクセス解析（Cookie） | Google Analytics 4（`_ga`, `_ga_*`） | 利用状況の分析・改善 | 任意（同意ベース） | 最長2年（Google の設定による） |
| 決済（Cookie） | Stripe が設定する不正防止用 Cookie | 決済時の不正防止 | 必須（決済ページのみ） | Stripe のポリシーによる |

localStorage の UI 状態は、ログインしていない閲覧者についてもブラウザ内に保存されますが、当社のサーバーには送信されません（ログイン後に同期される場合を除きます）。

### 8.2 Google Analytics 4 と同意

当社は、本サービスの利用状況を把握するために Google Analytics 4（GA4）を利用します。GA4 に関する取扱いは次のとおりです。

- 初回訪問時に表示される同意バナーで「同意する」を選択するまで、GA4 のタグは読み込まれず、データは送信されません
- GA4 では IP アドレスは匿名化（Google 側で保存されない）され、当社は個人を特定できる形で解析データを利用しません
- 同意はいつでも撤回できます。フッターの「Cookie設定」から選択を変更してください
- Google によるデータの取扱いは、Google のプライバシーポリシーおよび「Google のサービスを使用するサイトやアプリから収集した情報の Google による使用」をご確認ください
- Google Analytics オプトアウト アドオン（https://tools.google.com/dlpage/gaoptout）を利用してブラウザ全体で無効化することもできます

### 8.3 ブラウザ設定による制御

ブラウザの設定により Cookie の受け入れを拒否したり削除したりできます。ただし、必須の Cookie を無効化すると、ログインなど本サービスの一部機能が利用できなくなります。

### D.2 販売・共有を行わないこと

当社は、過去12ヶ月間に個人情報を「販売」しておらず、クロスコンテキスト行動広告のために「共有」もしていません。今後も行う予定はありません。また、16歳未満の消費者の個人情報を販売・共有していることを認識していません。

### D.3 カリフォルニア州の消費者の権利

- **知る権利**: 収集した個人情報のカテゴリ・具体的内容、収集元、収集目的、開示先のカテゴリを知る権利
- **削除権**: 収集した個人情報の削除を求める権利（法令上の例外を除く）
- **訂正権**: 不正確な個人情報の訂正を求める権利
- **販売・共有をオプトアウトする権利**: 当社は販売・共有を行っていないため、該当しません
- **機微な個人情報の利用を制限する権利**: 当社は機微な個人情報を収集していないため、該当しません
- **差別されない権利**: 権利を行使したことを理由に、サービスの拒否、価格・品質の差別を受けない権利

### D.4 行使方法

contact@chronos.tech に件名「California Privacy Request」でご連絡いただくか、設定画面（削除・訂正）から行えます。当社は10営業日以内に受領を確認し、45日以内に対応します（必要な場合はさらに45日延長し、その旨を通知します）。本人確認は、登録メールアドレスからの送信またはログイン状態により行います。権限を与えられた代理人による請求の場合、書面による委任の証明を求めます。

### D.5 Do Not Track・Global Privacy Control

当社は、個人情報を販売・共有していないため、Global Privacy Control（GPC）信号を受信した場合、その信号を販売・共有のオプトアウト要求として扱いますが、実質的な処理の変更は生じません。GPC信号を受信した場合、GA4 の同意が未取得の状態を維持します [推奨値]。ブラウザの「Do Not Track」信号については、業界標準が確立していないため、現時点では応答していません。

### D.6 Shine the Light

当社は、第三者のダイレクトマーケティング目的で個人情報を開示していません。
