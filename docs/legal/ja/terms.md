# Chronos 利用規約

最終更新日: 2026年8月17日
**Phase 1（日本 + 英語版）向け改訂版** — 段階戦略（docs/legal/rollout-plan.md）および批判的レビュー（docs/legal/ja/review-20260817.md）を反映した版です。

Chronos（クロノス）は、複数のレイヤーで文脈を重ねながら年表を作成し、共有するためのWebサービスです。本規約は、Chronosをご利用いただくうえでの約束ごとをまとめたものです。できるだけ平易な言葉で書いていますが、内容は法的な合意です。ご利用の前にお読みください。

本規約は「共通本文」（第1条〜第15条）と、お住まいの地域ごとに適用される「地域別付則」で構成されています。Phase 1では付則D（米国居住者向け）のみを設けています。付則が共通本文と異なる定めをしている場合、その地域にお住まいの方には付則の定めが優先します。EU/EEA・韓国・台湾向けの付則は、Phase 3（現地語版の提供開始時）に適用を開始する予定のドラフトとして、別文書（docs/legal/ja/phase3-addenda-terms.md）に置いています。

4. 本規約で使用する用語の意味は次のとおりです。
   - **年表**: ユーザーが本サービス上で作成するタイムライン。タイトル、説明、カテゴリ、レイヤー、イベント、公開設定などを含みます。
   - **イベント**: 年表を構成する個々の出来事。日付（または期間）、要約、詳細、信憑性、出典、割り当てられたレイヤーなどを含みます。
   - **レイヤー**: 年表の中で、イベントを文脈ごとに重ねて表示するための区分。
   - **ユーザーコンテンツ**: ユーザーが本サービスに投稿・作成・アップロードする年表、イベント、レイヤー、テキスト、出典情報、プロフィール情報、その他一切の情報。AI下書きをユーザーが編集・採用した内容も含みます。
   - **AI下書き**: ユーザーの入力をもとに、AIが年表やイベントの草案を生成する機能。
   - **AIアシスト**: 既存の年表やイベントの編集・補完・整形をAIが手伝う機能。本サービスの画面上では「AI Edit Assist」と表示されることがありますが、同じ機能を指します。
   - **AI機能**: AI下書きとAIアシストの総称。
   - **公開設定**: 年表ごとに設定できる「公開」「限定公開」「非公開」の3つの状態（第3条第4項）。本規約で鉤括弧付きの「公開」「限定公開」「非公開」は状態の名称を、鉤括弧のない「公開する」は年表を他の人が閲覧できる状態に置く行為を指します。
   - **Explore**: 公開年表を一覧・検索・閲覧できる、本サービス内の発見機能。
   - **Free / Pro**: 本サービスのプラン。手続は第7条に定め、内容と価格は料金ページに定めます。
   - **居住国**: あなたが通常の居所を有する国または地域。当社は、登録時にあなたが申告した国（申告がない場合は、アクセス元のIPアドレス等から合理的に推定した国）を居住国として扱い、決済時はStripe Checkoutで入力された請求先の国を居住国として扱います（付則総則）。
5. 本サービスの正式提供に先立ち、当社はウェイトリスト（メールアドレスの事前登録）を受け付けることがあります。ウェイトリストへの登録は、本サービスへの案内を受け取ることへの同意であり、アカウントの作成やサービスの提供開始を保証するものではありません。登録されたメールアドレスの取り扱いはプライバシーポリシーに従います。

### 第4条（AI下書き・AIアシスト）

1. 本サービスは、AI機能（AI下書きおよびAIアシスト）を提供します。AI機能は、Anthropic, PBC（以下「Anthropic」）が提供するClaude APIを利用して実現しています。
2. **未検証フラグとAI生成の表示。** AI下書きによって生成されたイベントには、初期状態で「未検証」の信憑性フラグが付与されます。これは、その内容がまだ誰にも確認されていないことを示すものです。ユーザーは、内容を確認したうえで信憑性フラグを変更し、必要に応じて出典を追加してください。**AI下書きに由来し、ユーザーがまだ検証していないイベントには、年表が公開または限定公開されている場合でも、公開画面上に「AI下書き・未検証」である旨の表示が維持されます。** この表示は、ユーザーが内容を確認して信憑性フラグを変更するまで解除されません。
3. **正確性の非保証。** AI機能の出力は、事実と異なる内容、古い情報、日付の誤り、実在しない出典、偏った記述などを含むことがあります。当社は、AI機能の出力の正確性、完全性、最新性、特定目的への適合性を保証しません。AI機能の出力を、医療、法律、金融、安全に関わる判断など、誤りが重大な結果をもたらす用途にそのまま利用しないでください。
4. **仕上げる責任はユーザーにあります。** AI機能の出力はあくまで「下書き」です。それを確認・修正し、自分の年表として公開または共有するかどうかを決めるのはユーザーです。AI下書きを編集・採用した内容はユーザーコンテンツとして扱われ、その内容についてはユーザーが責任を負います。
5. **入力の送信。** AI機能を利用する際、ユーザーが入力したプロンプト、対象となる年表やイベントの内容、その他AI機能の動作に必要な情報は、処理のためにAnthropicのサーバーに送信されます。Anthropicの商用利用規約上、APIを通じて送信された入力および出力はAnthropicのモデル学習に利用されないものとされており、当社はこの条件のもとでAnthropicを利用しています。ただし、Anthropicは不正利用の監視のために入力および出力を一時的に保持することがあります（保持期間の現行値はプライバシーポリシーに記載します）。送信される情報の詳細はプライバシーポリシーに定めます。第三者の個人情報や機密情報をAI機能に入力する場合は、ユーザー自身の責任で必要な同意や権限を確保してください。
