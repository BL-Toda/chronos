# Chronos コンテンツポリシーおよび通知・措置の手続

最終更新日: 2026年8月17日
Phase 1（日本 + 英語版）向け初版

本文書は、Chronos利用規約（以下「規約」）第6条に基づき、年表などのユーザーコンテンツについて、してはいけないこと、通報や申告の方法、当社が講じる措置、措置に対する異議申立の手続を定めるものです。本文書は規約の一部です。できるだけ平易に書いていますが、内容は法的な合意です。

## 1. 目的と適用

1. Chronosは、誰かが調べ、並べ、文脈を重ねた年表を共有する場所です。歴史・政治・カルチャー・科学・ビジネス・個人の出来事など、扱う題材は幅広く、意見が分かれる事項も含まれます。当社は、多様な視点の年表が安心して置かれる場所であるために、他者の権利や安全を害するコンテンツには対応します。
2. 本文書は、本サービス上のすべてのユーザーコンテンツ（年表、イベント、レイヤー、出典、プロフィール、ユーザー名、AI下書きを編集・採用した内容を含みます）と、それに関するすべての通報・申告に適用されます。
3. 通報・申告は、ユーザーでない方（アカウントを持たない方、権利者本人やその代理人、報道機関、公的機関など）からも受け付けます（第9節）。
4. 本文書は、規約第5条（禁止事項）を具体化するものです。本文書と規約が異なる場合は規約が優先しますが、本文書に定める手続は規約第6条の内容として適用されます。

## 2. 禁止コンテンツの具体例

規約第5条に定める禁止事項のうち、年表というかたちで特に起こりやすいものを例示します。列挙は限定的なものではありません。

**歴史・政治**
- 特定の歴史的事実（大量虐殺、戦争犯罪など）を否定・矮小化・賛美する表現のうち、あなたの居住国、または年表を閲覧できる閲覧者の居住国の法令で違法とされるもの
- 憎悪を扇動する表現、違法とされる組織の標章やスローガンをその宣伝目的で用いること
- 事実であるかのように装って捏造した出来事を、実際に起きたこととして公開すること（風刺・フィクションであることを明示している年表はこれに当たりません）
- 争いのある解釈を、争いがないかのように「確認済み」と表示すること（信憑性フラグは第3節を参照）

**実在の人物**
- 名誉毀損: 実在の人物や団体について、事実に反する記述や、根拠を示さない断定的な非難を公開すること
- なりすまし: 他人・他社・公的機関・当社を装う年表やプロフィール
- 公人の公的な活動に関する記述は禁止されませんが、その場合も出典を示し、名誉毀損や侮辱に当たらないよう配慮してください

**生存者の個人情報**
- 生存する個人の氏名、住所、連絡先、所属、顔写真、健康・信条・犯罪歴などの機微な情報を、本人の同意なく掲載すること（いわゆる晒し行為を含みます）
- 個人の私生活上の出来事（家族関係、病歴、交友関係など）を本人の同意なく年表にすること。「個人・ライフ」カテゴリで自分以外の生存者を扱う場合は特に注意してください
- 生存する個人の情報を含む年表を公開する場合、投稿者自身が居住国の個人情報保護法令上の義務を負うことがあります

**著作物**
- 書籍、記事、Webサイト、画像などの他人の著作物を、引用の範囲を超えて転載すること。出典を明記して要旨を自分の言葉で記述することは通常問題ありません
- 他のユーザーの年表を、自分の作品として再投稿すること、または無断で複製して別の年表を作成すること
- AI下書きの出力に含まれる第三者の著作物や権利物を、確認せずに公開すること

**その他**
- 性的に露骨な内容、暴力を賛美・扇動する内容、ハラスメント
- 児童の性的搾取に関わる内容（一切許容されず、発見次第、法令に従い関係機関に通報します）
- 通報制度の濫用（虚偽の通報、嫌がらせ目的の通報、大量通報）
- AI機能をAnthropicの利用ポリシーが定める禁止用途に用いること（規約第4条第10項）

## 3. 信憑性フラグと当社の中立性

1. イベントには「確認済み」「諸説あり」「未検証」の信憑性フラグを設定できます。これは作成者の自己申告であり、当社による検証を意味しません。AI下書きに由来し未検証のイベントには、公開画面でも「AI下書き・未検証」の表示が維持されます（規約第4条第2項）。
2. 当社は、年表に記載された歴史的・政治的・社会的な事項について、いかなる立場も表明しません。年表が本サービスに掲載されていること、Exploreに表示されていること、当社が通報に対して措置をとらなかったことは、当社がその内容を支持し、または事実として認めたことを意味しません。
3. 「内容に同意できない」「解釈が違う」という理由だけでは、当社は措置をとりません。そのような場合は、別の年表を作成して異なる文脈を示すことをおすすめします。当社が措置をとるのは、規約・本文書・法令に違反するコンテンツです。
4. 当社は、通報や申告を、規約・本文書・法令に照らして、適時に、勤勉に、恣意的でなく、客観的に審査します。審査は原則として人が行い、自動化された手段は明らかなスパムやマルウェアの検知など補助的な範囲で用います。

## 4. 通報の種類

当社は、次の2種類を分けて受け付けます。どちらに当たるか迷う場合は、Aで送ってください。当社が判断して振り分けます。

### A. 規約違反の通報（匿名可）

規約または本文書に違反すると考えられるコンテンツについて、どなたでも通報できます。

- 方法: 年表画面の通報ボタン、または contact@chronos.tech へのメール
- 記載してほしいこと: 対象のURL、該当するイベントやレイヤーの特定、違反すると考える理由（できるだけ具体的に）
- 氏名や連絡先の記載は任意です。記載がない場合、受領確認と結果通知はできません
- 通報ボタンからの通報は、ログインしていれば通報者のアカウントに紐づけて記録しますが、対象ユーザーには開示しません

### B. 権利侵害の申告（氏名・連絡先が必須）

自身の権利（著作権、商標権、名誉、プライバシー、肖像など）、または自身が代理する者の権利が侵害されていると考える方は、次の事項を含めて申告してください。ユーザーでない方も申告できます。日本の特定電気通信役務提供者の損害賠償責任の制限及び発信者情報の開示に関する法律（プロバイダ責任制限法）に基づく送信防止措置の申出、および海外の類似の手続（DMCA通知に相当するもの）は、この方法で受け付けます。

- 申告者の氏名（法人の場合は名称と担当者名）と連絡先（メールアドレス。必要に応じて住所・電話番号）
- 代理人の場合は、権利者との関係と代理権を示す情報
- 侵害されていると考える権利の内容（例: 著作権のある著作物のタイトル、名誉毀損とされる記述の対象者）
- 対象コンテンツのURLと、該当箇所の特定（年表名、イベント名、レイヤー名など）
- 侵害であると考える理由の説明（著作権の場合は権利を有することの根拠、名誉毀損・プライバシーの場合はどの記述がなぜ権利を侵害するか）
- 申告内容が正確であり、申告者が権利者本人または正当な代理人であることを、善意で（真実であると信じて）宣誓する旨の記載
- 送付先: contact@chronos.tech（件名に「権利侵害の申告」と記載してください）またはアプリ内の申告フォーム

必須事項が欠けている申告には、当社から補正をお願いすることがあります。補正がない場合、Aの通報として扱うことがあります。

## 5. 手続

1. **受領確認。** 当社は、通報・申告を受け付けたときは、連絡先が記載されていれば、受領を確認する連絡を行います（原則として2営業日以内）。
2. **審査。** 当社は、対象コンテンツ、通報・申告の内容、必要に応じて対象ユーザーからの意見（第6節）を踏まえ、規約・本文書・法令に照らして審査します。緊急性の高いもの（児童の安全、差し迫った暴力、生存者の機微な個人情報の晒しなど）は優先して扱います。
3. **措置。** 審査の結果、違反または違法と判断した場合、第7節の措置のうち、違反の内容と程度に見合ったものを選びます。判断が難しい場合、当社は法令に基づき暫定的に表示を制限したうえで審査を続けることがあります。
4. **結果通知。** 当社は、通報者・申告者（連絡先が記載されている場合）に、措置をとったかどうかを回答します。当社が措置をとった場合、対象ユーザーには、緊急を要する場合、法令上通知が禁じられている場合、または通知が本サービスの安全を損なう場合を除き、次の事項を含む理由の陳述を通知します。
   - 措置の内容と、対象となったコンテンツ
   - 判断の基礎となった事実（通報・申告に基づくか当社の判断によるか、自動検知によるかを含みます）
   - 根拠となる規約・本文書の条項、または法令
   - 利用できる救済手段（異議申立の方法と期限）
5. **異議申立。** 対象ユーザーは、通知を受けた日から14日以内に、アプリ内または contact@chronos.tech から異議を申し立てることができます。異議には、措置が誤っていると考える理由と、必要に応じて根拠（権利を有することの証明、出典、本人の同意の存在など）を添えてください。通報者・申告者も、措置をとらないという結果に対して、同じ期間内に再検討を求めることができます。
6. **再審査。** 当社は、異議の内容を、最初の判断に関与していない担当者を含めて再審査し、結果とその理由を回答します（原則として14日以内。追加の調査が必要な場合はその旨をお知らせします）。再審査の結果、措置が誤っていたと判断した場合は、速やかにコンテンツの表示を回復し、アカウントの状態を戻します。
7. **記録。** 当社は、通報・申告・措置・異議の記録を、対応完了後3年間保存します。対象の年表が削除された後も、当時のタイトルとURLの記録は残ります（プライバシーポリシー参照）。

## 6. 発信者への意見照会

1. 権利侵害の申告（B）を受けた場合、当社は、措置の要否を判断するために、対象コンテンツを投稿したユーザー（発信者）に対して、申告の内容を伝え、7日程度の期間を定めて意見を照会することがあります。これは、プロバイダ責任制限法に準じた手続であり、当社が申告のみで一方的に判断することを避けるためのものです。
2. 意見照会にあたって発信者に伝えるのは、申告の内容（どのコンテンツのどの部分が、どのような理由で、どの権利を侵害するとされているか）です。**通報者・申告者の氏名および連絡先は、法令に基づく場合または本人の同意がある場合を除き、発信者に開示しません。** ただし、申告の内容から申告者が推知できることがあります（例: 対象記述の当事者本人が申告した場合）。
3. 発信者が期間内に意見を述べない場合、または申告に理由があると認められる場合、当社は措置をとることがあります。発信者が反論し、当社が判断できない場合は、当事者間での解決をお願いすることがあります。
4. 明白な侵害（児童の性的搾取、明らかな全文転載など）や、緊急を要する場合は、意見照会を経ずに措置をとることがあります。

## 7. 措置の種類

当社は、違反の内容と程度に応じて、次の措置のうち一つまたは複数をとります。軽い違反にはできるだけ軽い措置を選び、警告のみで済ませることもあります。

| 措置 | 内容 |
|---|---|
| 警告 | 該当箇所と理由を伝え、修正を求めます。期限内に修正されない場合は次の措置に進みます |
| 表示制限 | Exploreや公開プロフィールへの掲載停止、おすすめからの除外、埋め込み表示やOGP画像生成の停止。年表自体はURLから閲覧できます |
| 非公開化 | 年表の公開設定を「非公開」に変更します。作成者は閲覧・編集・書き出しができ、修正後に再公開できます |
| 一部削除 | 該当するイベント、レイヤー、出典、プロフィール項目などを削除します |
| 削除 | 年表全体を削除します。作成者には削除前に書き出しの機会を提供するよう努めます（明白な違法コンテンツを除きます） |
| AI機能の停止 | AI機能を禁止用途に用いた場合、AI機能の利用を停止します |
| アカウントの一時停止 | 一定期間ログインできない状態にします。公開年表は表示制限または非公開化されることがあります |
| アカウントの終了 | アカウントを終了（削除）します。データの扱いは規約第11条によります |
| 公的機関への情報提供 | 法令に基づき、捜査機関その他の公的機関に情報を提供します |

## 8. 反復侵害者ポリシー

1. 当社は、権利侵害の申告や規約違反の通報に基づく措置を繰り返し受けるユーザー（反復侵害者）のアカウントを、適切な状況において終了します。
2. 目安として、12ヶ月の間に、異議申立で覆らなかった措置（警告を除きます）を3回受けた場合、当社はアカウントの終了を検討します。ただし、違反の重大性（1回でも終了に相当するもの、例: 児童の性的搾取、明白で大規模な著作権侵害、生存者の機微な情報の晒し）と、悪質性（同じ内容を繰り返し再投稿する、複数アカウントで回避するなど）を考慮し、回数にかかわらず終了することがあります。
3. 反復侵害者としてアカウントを終了されたユーザーは、新たなアカウントを作成できません。
4. 反復侵害者としての終了に対しても、第5節の異議申立ができます。

## 9. 権利者以外（非ユーザー）からの申告窓口

1. 権利を侵害されたと考える方は、Chronosのアカウントを持っていなくても、第4節Bの方法で申告できます。年表画面の通報ボタンはログインなしでも利用できます。
2. 報道機関、研究者、公的機関、業界団体などからの照会や、法令に基づく開示請求・削除要請は、contact@chronos.tech で受け付けます。当社は、法令に基づく要請には法令に従って対応し、それ以外の要請には本文書の手続で対応します。
3. 未成年者に関する内容や、生命・身体の安全に関わる緊急の事案は、件名に「緊急」と記載してください。当社は優先して対応しますが、差し迫った危険がある場合は、まず警察などの緊急連絡先に連絡してください。
4. 発信者情報の開示については、当社はプロバイダ責任制限法その他の法令に従い、法令の要件を満たす場合に限って対応します。申告者に対して、当社の判断で発信者の情報を任意に開示することはありません。

## 10. 本文書の変更

1. 本文書を変更する場合、規約第12条の手続に従います。手続や措置の基準に関する重要な変更は、効力発生の30日前までにお知らせします。
2. 当社は、法令の改正やユーザーからの意見を踏まえ、必要に応じて本文書を見直します。定期的な公表・報告は行いません（法令上義務づけられる場合を除きます）。

## 11. 連絡先

通報、権利侵害の申告、異議申立、その他本文書に関するお問い合わせは、次の連絡先までお願いします。

- メール: contact@chronos.tech
- アプリ内: 年表画面の通報ボタン、設定画面の「異議申立」
- 事業者情報: 規約第13条第2項に記載しています
