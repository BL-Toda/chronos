## 総評

画面単体の完成度・トークン遵守・トーンの統一は高水準で、コア体験（マルチレイヤー、AI生成フロー、AI Edit Assist）は仕様とプロトタイプがよく対応している。一方で「**個々の画面は良いが、画面と画面・画面と仕様の“あいだ”が壊れている**」段階にある。具体的には、

1. **作成→公開→共有が断絶** — 公開設定（public/unlisted/private + share_id）を操作するUIが全27ファイルのどこにも無い。DB・RLS・利用規約・APIまで定義済みなのにUIだけが欠番。
2. **期間イベントがデータモデルに存在しない** — UIの中核（viewer / creation-flow / period系4画面）なのに、eventsテーブルは `event_date` 単一で、API・AI生成スキーマにも終了日が無い。実装時に最大の手戻り要因。
3. **「現行」が資料ごとに食い違う** — サイトマップ（2026.02.12から未更新）にExploreが存在せず、LP5版・作成者ビュー・マイページ定義の正がsitemap / design-system / CLAUDE.mdでバラバラ。
4. **数値の分裂** — プラン数値が3通り（月3回¥800 / 月10回 / ¥980）、年額¥6,800の「2ヶ月分お得」は計算が合わない、lp-launchには実在しない実績数値（8,100+ユーザー等）。
5. **共有環境で踏める実害バグ** — chronos-screens.html にDOM破損3件（タブ切替で画面が空になる等）。
6. **横断的な未着手領域** — モバイル導線（860px以下でフィルタ・ナビが消える）、アクセシビリティ基礎（aria/tabindex使用0件、text3のコントラスト2.8:1）、空状態・エラー状態、モデレーション/通報。

3. 【高】作成フローに公開・保存ステップが無く、作成→共有が断絶（「公開」「保存」「共有」がgrep 0件）
4. 【高】LP5種の現行が判別不能（sitemap/design-system→lp.html、CLAUDE.md→lp-v2、実際の最新仕様反映→lp-v3）
5. 【高】既存年表の編集画面が未作成（/t/[slug]/edit は design-system 自ら「未作成」と明記）
6. 【高】年表削除フローが全欠落。アカウント削除も確認モーダル無しのワンクリック
7. 【中】グローバルナビが3方式併存（explore型トップナビ / screensのロゴのみ / 旧ボトムナビ）、「作成/年表をつくる」等のラベル揺れ
8. 【中】エラー・失敗状態がゼロ（AI生成失敗・再試行、authバリデーションエラー等）
9. 【中】「マイページ」の定義が資料間で別物（/dashboard vs /@username）。公開プロフィール画面が実在しない
10. 【中】いいねカウント表示はあるが、いいねを押せる画面がどこにも無い
11. 【中】onboarding v1が現行(v2)と競合したまま残存。v2完了画面の遷移先がalertスタブ
12. 【低】onboarding-v2にトーン規約違反「〜完成しました！」「完了！」（全ファイル唯一の「!」違反）
13. 【低】レイヤーカラーの色数が資料間不一致（CLAUDE.md 5色 vs sitemap・実装 7色）
