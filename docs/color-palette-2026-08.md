# Chronos カラーパレット（2026-08-25確定・正本）

`docs/design-system-2026-08.md` の §1 を色に絞って詳細化したもの。実装は `:root` にこの順で定義する。

## 1. 背景（4段 + 状態2段）

```css
--bg:#0A0A0C;        /* ページ地 */
--bg2:#0E0E11;       /* モーダル・サブ面・フッター */
--card:#16161A;      /* カード・入力欄・コードブロック */
--card-h:#1A1A1F;    /* ホバー時のカード */
--card-a:#1E1E24;    /* タップ/アクティブ時のカード */
```

- ホバー背景は **`--card-h` の1種だけ**。`#1B1B20` は廃止（`--card-h` に統合）
- `--card-a` は `:active` 専用

## 2. テキスト（4段 + 反転）

```css
--text-h:#F5F2ED;    /* 見出し・強調 */
--text:#E8E4DE;      /* 本文 */
--text2:#9A9590;     /* 説明・副情報 */
--text3:#7A7570;     /* メタ・出典・ラベル */
--text-max:#FFFFFF;  /* ホバー時の見出しなど、最前面の一段だけ */
--on-light:#0A0A0C;  /* 明色ボタン上の文字 */
```

旧 `#8A8680` / `#5A5754` は廃止。

## 3. クローム（モノトーン）

```css
--accent:#B8B4AE;                      /* ラベル・補助テキスト（旧ゴールド #C8A87E を置換）*/
--accent-soft:rgba(232,228,222,0.07);  /* 選択中の背景 */
--accent-med:rgba(232,228,222,0.14);   /* 強めの選択背景 */
--border:rgba(232,228,222,0.09);       /* 通常の枠線 */
--border2:rgba(232,228,222,0.18);      /* ホバー・強調の枠線 */
--line:rgba(232,228,222,0.12);         /* 罫線・軸線 */
```

**彩度を持つ装飾はここには存在しない**。ゴールド `#C8A87E` は全画面で廃止済み。

## 4. レイヤーカラー（7色・データ専用）

| 名前 | base（`--c-<name>`） | dim（`--c-<name>-d`） | bar |
|---|---|---|---|
| blue | `#5B9BD5` | `rgba(91,155,213,0.12)` | `rgba(91,155,213,0.22)` |
| green | `#7BC67E` | `rgba(123,198,126,0.12)` | `rgba(123,198,126,0.22)` |
| pink | `#D4849A` | `rgba(212,132,154,0.12)` | `rgba(212,132,154,0.22)` |
| gold | `#C8B87E` | `rgba(200,184,126,0.12)` | `rgba(200,184,126,0.22)` |
| purple | `#9E7EC8` | `rgba(158,126,200,0.12)` | `rgba(158,126,200,0.22)` |
| teal | `#5BBCB4` | `rgba(91,188,180,0.12)` | `rgba(91,188,180,0.22)` |
| orange | `#D4A05A` | `rgba(212,160,90,0.12)` | `rgba(212,160,90,0.22)` |

- **画面上で彩度を持ってよいのはこの7色だけ**（カテゴリ色・レイヤードット・イベントカードの左バー・チップ）
- `dim` は選択中の背景やタグの地に、`bar` は viewer のレーンに使う
- viewer は `--c-*` からJSで7色ぶんのクラス（`.lane.c-blue` 等）を生成する。個別の色をCSSに直書きしない

## 5. 機能色

```css
--danger:#D45A5A;    /* 削除・破壊的操作・入力エラー・上限警告 */
```

成功・情報は専用色を持たず、`--c-green` / `--text2` を使う。

## 6. 例外（トークン化して明示する）

意図的に上記の外にある色。**必ずコメント付きでトークン化し、直値で散らさない**。

### 6-1. 外部ブランド色（変更不可）
```css
--brand-google-blue:#4285F4; --brand-google-green:#34A853;
--brand-google-yellow:#FBBC05; --brand-google-red:#EA4335;
--brand-x:#1DA1F2;
```

### 6-2. ライトテーマのモック（chronos-share-embed の埋め込みプレビュー）
```css
--light-bg:#F8F6F3; --light-surface:#EEEAE5; --light-text:#3C3A37;
--light-c-blue:#4A88C2; --light-c-pink:#C07088; --light-c-teal:#4AA8A0;
```

### 6-3. UIモック内の装飾（macOSウィンドウの信号）
```css
--mock-red:#FF5F57; --mock-yellow:#FFBD2E; --mock-green:#28C840;
```

### 6-4. 明色ボタンの押下
```css
--text-h-a:#EDE9E3;  /* --text-h 地のボタンの :active */
```

### 6-5. OGPパターン背景（chronos-ogp-templates）
パターンごとの質感差（`#0C0C0F` `#0B0B0E` `#08080B` など）。`--bg` 近傍の微差なので当該ファイル内でのみ定義してよい。

### 6-6. アバターのSVGアートワーク（chronos-avatars）
16種のアバターはそれぞれ固有の配色（暗色の地 + レイヤー7色 + ゴールド）を持つ **コンテンツ**。
UIのパレットとは別物なので、このファイル内のSVG配色は本ルールの対象外とする。

### 6-7. 明色ボタンの状態
```css
--btn-light-h:#D0CCC6;  /* --text-h 地のボタンのホバー */
--btn-light-a:#A6A29C;  /* 同 :active */
```

## 7. 禁止

- 新しい彩度色の追加（レイヤー7色の外）
- 装飾目的のゴールド・オレンジ
- 同じ役割に複数の値（ホバー背景を画面ごとに変える等）
- 例外色を直値で散らすこと（必ず 6. のトークン経由）
