Implementation Spec

サイズ: 1200×630px（OGP標準）
フォーマット: PNG（サーバーサイドで動的生成。Vercel OG / Satori推奨）
動的要素: 年表タイトル / カテゴリ名 / 作成者 / イベント数 / 検証率
パターン割り当て:
　テクノロジー → Layered Waves　/　カルチャー → Topographic　/　政治・社会 → Aurora
　サイエンス → Dot Matrix　/　ビジネス → Geometric Grid　/　その他 → Gradient Mesh（デフォルト）
共通要素: 右上にChronosロゴ（シンボル＋ワードマーク）。下部にグラデーションオーバーレイでテキスト視認性確保。
フォント: タイトル = Erode Medium、メタ情報 = JetBrains Mono / DM Sans
