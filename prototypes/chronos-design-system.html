03 — Component Catalog
コンポーネントカタログ
プロトタイプのCSS class → Reactコンポーネント名の対応と、各コンポーネントのProps定義。
ATOMS（最小単位）
LayerChip
レイヤーの ON/OFF トグル。タイムライン上部に固定表示。
labelstring表示名（例: "製品"）
colorLayerColorlayer.blue / layer.pink 等
activebooleanON/OFF状態
onToggle() => voidトグル時コールバック
AxisDot
タイムライン中央軸上のドット（点イベント用）。
colorLayerColorレイヤー色
AxisPeriodMark
タイムライン中央軸上の横バー（期間イベント開始/終了用）。
colorLayerColorレイヤー色
type'start' | 'end'開始: 不透明 / 終了: 半透明
EventTag
イベントカード内のタグ。レイヤー名、信憑性、期間ラベル。
labelstring"製品", "✓ 確認済み", "期間 12年"
variant'layer' | 'cred' | 'period'色バリエーション
color?LayerColorvariant='layer'の場合のレイヤー色
PeriodBar
期間イベントの進捗バー（開始年〜終了年）。
startYearstring"1985"
endYearstring"1997" / "現在"
colorLayerColorレイヤー色
fillPercent?number進行中の場合 0–100
LaneLine
タイムライン左側のレーンバー（期間の縦線）。
colorLayerColorレイヤー色
position'start' | 'mid' | 'end' | 'start-end'角丸の方向
activebooleanレイヤーONなら true
periodIdstring所属する期間ID
MOLECULES（組み合わせ）
EventCard
点イベントのカード。アコーディオン展開で詳細・タグを表示。
eventTimelineEventイベントデータ
expandedbooleanアコーディオン状態
onToggle() => void展開/折りたたみ
isCenterFocusboolean画面中央にあるとき true
PeriodCard
期間イベントの開始カード。PeriodBar + アコーディオン展開。
periodTimelinePeriod期間データ
expandedbooleanアコーディオン状態
onToggle() => void
isCenterFocusboolean
PeriodEndLabel
期間イベントの終了行。破線ボーダー + ミニバー + テキスト。
periodTimelinePeriod期間データ
YearSeparator
年代区切り行。大きな年ラベル + フェードライン。
yearstring"1970s", "2000s" 等
ORGANISMS（画面構成単位）
TimelineRow
タイムラインの1行。レーン領域 + 軸 + コンテンツの3カラム構成。
lanesLaneConfig[]左側レーンバーの配置
axisElementReactNodeAxisDot or AxisPeriodMark
childrenReactNodeEventCard / PeriodCard / YearSeparator
layersstring[]この行が属するレイヤー名
visiblebooleanレイヤーフィルタ後の表示状態
TimelineView
タイムライン全体。LayerControls + Legend + TimelineRow[] + center-focus ロジック。
timelineTimeline年表データ全体
mode'author' | 'public'作成者ビュー / 公開ビュー
ShareSheet
共有シート（ボトムシート）。URL コピー + SNS共有 + 埋め込み。
urlstring共有URL
titlestring年表タイトル
openboolean
onClose() => void

05 — Data Model
データモデル
types/timeline.ts
type Credibility = 'verified' | 'disputed' | 'unverified';

type LayerColorKey = 'blue' | 'pink' | 'teal' | 'green'
                   | 'gold' | 'purple' | 'orange';

interface Layer {
  id: string;
  name: string;          // "製品"
  color: LayerColorKey;  // "blue"
}

interface TimelineEvent {
  id: string;
  type: 'point';
  layerId: string;
  date: string;          // "2007.01"
  title: string;
  summary?: string;
  credibility: Credibility;
  sourceUrl?: string;
  tags?: string[];
}

interface TimelinePeriod {
  id: string;
  type: 'period';
  layerId: string;
  startDate: string;     // "1985"
  endDate: string;       // "1997" | "present"
  title: string;
  summary?: string;
  credibility: Credibility;
  sourceUrl?: string;
}

type TimelineItem = TimelineEvent | TimelinePeriod;

interface Timeline {
  id: string;
  slug: string;          // URL用: "apple-history-toda"
  title: string;
  emoji?: string;
  description: string;
  authorId: string;
  authorUsername: string;
  visibility: 'public' | 'limited' | 'private';
  layers: Layer[];
  items: TimelineItem[];
  createdAt: string;
  updatedAt: string;
}

interface User {
  id: string;
  username: string;      // "@toda"
  displayName: string;
  plan: 'free' | 'pro';
  timelinesCount: number;
  aiGenerationsUsed: number;
  aiGenerationsLimit: number; // free: 5, pro: Infinity
}

08 — Tech Stack
推奨技術スタック
カテゴリ技術理由
フレームワークNext.js 15 (App Router)SSR/SSG混在、OGP対応、RSC
言語TypeScript型安全、データモデルの厳密化
スタイリングCSS Modules + CSS変数既存トークンをそのまま移植。Tailwindも併用可
フォントnext/font + @fontsourceErodeは@fontsource未対応のためセルフホスト
アニメーションFramer MotionfadeUp、アコーディオン、シート、center-focus遷移
状態管理React state + Context小規模。必要に応じてZustand追加
データ取得SWR or TanStack Queryキャッシュ・再検証
認証NextAuth.js (Auth.js)Google / Magic Link
DBSupabase (PostgreSQL)認証統合、リアルタイム（将来の共同編集）
AI生成Anthropic Claude API年表自動生成、AI Edit Assist
OGP画像@vercel/og (Satori)動的OGP生成
ホスティングVercelNext.jsとの親和性、Edge Functions
