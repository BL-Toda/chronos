エンジニア向け技術概要
AIで年表を自動生成し、複数レイヤーを重ねて出来事の文脈を可視化するWebアプリ。
プロトタイプ（HTML）と推奨技術スタックの概要です。
Prototypes
プロトタイプ
年表ページ（公開ビュー）
chronos-viewer.html
閲覧者が見る公開年表。レイヤーON/OFF、期間バー付きレーン表示、アコーディオン展開、センターフォーカス、共有シート。このUIがプロダクトの中核。
ランディングページ
chronos-lp.html
機能訴求型LP。Canvas背景アニメーション、インタラクティブなレイヤーデモ、年表カード一覧、料金プラン。
Recommended Stack
推奨技術スタック
フロントエンド
Next.js（React）+ TypeScript。App Routerで公開年表はSSR（OGP・SEO対応）、作成・編集画面はClient Component。スタイリングはCSS Modules + CSS変数。プロトタイプで確定済みのデザイントークン（カラー7色、タイポグラフィ3書体、8段階のType Scale）をそのまま移植可能。アニメーションはFramer Motion。
バックエンド
Next.js API Routes + Supabase（PostgreSQL）。MVP段階ではバックエンドを別途立てず、Next.jsのServer ActionsとSupabaseの組み合わせで十分。認証（Google / Magic Link）、DB、ストレージがSupabaseで一気に揃う。
AI年表生成
Claude API（Anthropic）。テーマ入力から年表データ（JSON）を構造化生成。点イベント・期間イベント・レイヤー分類・信憑性フラグまで一括出力。AI Edit Assist（編集支援）も同APIで実現。
インフラ
Vercel（フロント）+ Supabase（DB）。VercelはNext.jsとの親和性が高く、Edge Functionsで動的OGP画像生成（@vercel/og）にも対応。Supabaseはマネージドで運用負荷が低い。
